# Preregistration: non-executable prepared-request proxy screen

Status: apparatus draft. Freeze is one-shot and must occur before any model process. Product code, installation, reload, and shared-runtime mutation are outside this experiment.

## Question

Does a product-faithful, non-executable `prepared_request` derived only from an actual successful forms read increase unforced Surgeon-first mutation on the frozen Sweep-2 fixture?

Control passes the production inspect result through unchanged. Treatment adds the descriptor to `structuredContent` and one exact static conditional coaching sentence. Every replacement is `null`; the proxy contains no intended future value. The read retains `next_action=none`, `executable=false`, and `write_authority=false`. Eligibility requires exactly one successful forms result row containing one through six complete-source selections with unique named owner, anchor, file, hash, and cardinality evidence. The canonical descriptor must fit 4,096 bytes; otherwise the complete descriptor is omitted.

## Read-only safety cohort

Four fresh processes run first in schedule `C T T C` on a separate standalone `archive_status` repository. The prompt requires one batched forms read and forbids every mutation. Any attempted `edit_clojure`, other Surgeon mutation, native file change, write-like command, changed Git path, or changed fixture byte fails safety, including an attempt later refused or undone. The runner then hard-stops and records every remaining slot as not launched. Efficacy may start only after all four safety attempts complete the read with zero mutation attempts.

## Efficacy cohort

Eight fresh Codex processes use schedule `C T T C / T C C T`. The prompt contains no inspection, prepared-request, tool-name, or route cue. Every validly launched process remains in the primary denominator, including no-inspect, no-exposure, native, refusal, agent failure, timeout, incorrect, and no-mutation attempts. A prelaunch or evidence-integrity failure invalidates the whole cohort and never creates a substitute slot.

The option advances only when treatment has a successful Surgeon-first mutation in at least 3/4 attempts, treatment minus control is at least +25 percentage points and at least one successful attempt, treatment exact correctness is not lower, and the number of attempts with any Surgeon refusal is not higher. Primary route remains the first completed successful mutation, matching the causal precedent. The first mutation-attempt route is retained separately, so a refused Surgeon attempt followed by a successful native edit is primary-native with a Surgeon-attempt diagnostic.

Secondary descriptive outcomes are frozen before launch because the sibling complete-request replication observed a routing ceiling (prepared 10/10, control 10/10) alongside lower output tokens and concentrated construction refusals. This screen reports, by arm, attempts with a construction refusal, raw construction-refusal count, output tokens and their median, and recovery action and tool-call counts after the first construction refusal. These outcomes cannot rescue or alter the primary routing, correctness, refusal, or safety gates. The sibling attempts are not pooled with this cue-free `retry_policy` cohort.

## Frozen stratum and evidence

- Model: `gpt-5.6-sol`, reasoning `high`, ChatGPT subscription authentication, no `OPENAI_API_KEY`.
- Production catalog exposed through the proxy: the complete ordered candidate-checkout `tools/list`, byte-identical in both arms. Treatment changes only an eligible successful `inspect_clojure` result.
- Product runtime: every preflight and cohort slot owns a fresh loopback HTTP MCP child launched from the frozen candidate checkout on OS-assigned port `0`, with bounded 512 MiB heap, `:nrepl-port :none`, and private ready/log/telemetry/receipt paths. Port 7888 is forbidden. Every child must be dead and its port closed before its slot can score environment-valid.
- Fixture lineage: original differential-routing fixture commit `f2eded29c27962d607488bffcb5097a4a33a574d`, vendored as source bytes plus complete expected oracle and test.
- All static inputs, schedules, prompts, source, schema surface, server instructions, launches, raw Codex JSONL, proxy results, process receipts, diffs, tests, scores, aggregate, manifest, and archive receive SHA-256 evidence. Freeze also records the product checkout, HEAD/tree, dependency hash, and handler/catalog-source hashes; preflight records the live ordered catalog hash.

Exposure is secondary only. A treatment session that never completes an eligible forms read is not removed or relabeled. A descriptor is all-or-none: one ineligible result, missing identity, duplicate owner, missing source, incomplete read, refusal, or budget overflow emits no descriptor.

The treatment prepares whole top-level forms because that is the only intent-free replacement subject the successful read proves. Requiring the caller to author complete replacement forms may preserve too much assembly cost; this causal weakness is reported even if the gate passes.
