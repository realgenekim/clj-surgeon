# Registration first-contact gate repair

The [registration design](../intent/test-registration/design.md) and REGNS-006
own this repair of Sol REAL-GATE-001 at `bfbec7f9`. Standing approval covers the
design, requirements, RED witnesses, implementation, documentation and verification.

The observable contract is one local checklist per defective namespace and one
repository-level count row. A complete registered namespace must not inherit
another namespace's count discrepancy. The repository row names disk-minus-manifest
subjects; if that set is empty, count-only drift has no namespace remedy. The
first ordinary gate failure must retain the requested lane/runtime for a subject
with local defects. Existing enrollment, executed controls and census ownership
remain unchanged.

The behavior matrix independently removes each combination of lane/runtime,
author metadata, count pin, adoption and control coverage from a freshly enrolled
copied repository. Mask 0 proves the seed is valid; masks 1–31 run the production
coordinator's cold lane argv. Mask 4 is the repository-only case. The oracle checks
the first failure, every emitted checklist subject, exact remedy, count-row
cardinality, absence of test errors and the existing 8000 ms namespace budget.
The fast representative exercises mask 1 against real copied registration files.
No test body, repository Var or diagnostic is replaced in either class witness.

RED must preserve the actual old first failure naming admit-patch-test. GREEN
requires the complete battery wall, focused lane walls with/without Sol's plant,
and a copied-repository `make test-fast` refusal whose first failure names the
plant. The report retains that first failure verbatim, lint and census results,
and protected ledger hashes. Neither the full test suite nor the full battery
suite runs on the live tree. Temporary roots are inherited from the caller;
product paths are repository-relative. Qualified test names stay intact, and the
obsolete seam-matrix byte digest is deliberately retired.

The actual cold matrix costs 337496–393668 ms, exceeding the battery namespace's
300000 ms default while remaining below the 1800000 ms cadence limit. Its scoped
namespace override is 800000 ms, following the existing approximately 2x measured
cost convention. Every nested fast gate retains and asserts its 8000 ms limit.
