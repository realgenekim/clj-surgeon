# Refactor census, piece 1
History: replaces PR 86, closed after its third review round; preserves initializer/body self-references.
Contract: `bb bin/refactor-census DRYER ROOT` reads only; it parses dryer blocks, merges overlapping ranges, and groups connected copies into sorted families. Adjacent ranges remain distinct copies.
Each accepted copy reports its top-level name, public/private visibility (`defn-`, `^:private`, `defn`, `def`), and bare/aliased caller-file counts across `src/` and `test/`; repeated references count once per file and spelling class, and `files` is their union. Qualified spellings include full namespace names. Static references include value uses; lexical locals and quoted data are excluded by the existing analyzer. This is a source census, not macro expansion or dynamic call analysis.
Inputs use `<repo>/` or ROOT-prefixed paths (ROOT may end in `/`) and ordinary vector requires (`:as`, explicit `:refer`). A range starting at the ns form is DRIFT by design. Other ranges must start exactly at a current top-level form start and end within that form; otherwise print `DRIFT <path>:<start>-<end> (form boundaries moved)`, count `drifted=N`, and exclude it from owner counts. Empty or whitespace-only dryer input is a valid zero-family census. Other input must begin with a `DUPLICATE score=` header after optional blank lines; each nonblank location line must match two spaces, a path, colon, decimal start, hyphen, decimal end, and optional trailing whitespace. Each block must contain at least two location lines; fewer locations fail with `block with <k> locations at line N`, where N is the header line. Paths must start with `<root>/` after placeholder expansion; a foreign path fails with `path outside root: <path>`. Reversed ranges fail with `reversed range: <start>-<end>`. Location failures name their input line. Missing blocks or malformed locations print `refactor-census: unparseable dryer input: <reason> at line N` on stderr and exit 2 without a summary; unreadable input also exits 2. No source evaluation or writes. Copies include drifted locations; public/private counts include accepted owners only. Output has one line per family followed by the `refactor-census: families=N copies=M public-copies=P private-copies=Q drifted=D` summary.
Pure matrix: empty/whitespace/CRLF/root-prefixed/trailing-slash parsing; garbage, malformed locations, zero/one-location blocks at EOF/before blanks/before another header, foreign paths and reversed ranges, with line-numbered refusals; disjoint, overlapping, transitive and repeated families; private/public definitions; same-namespace, referred, aliased and fully qualified callers; repeated uses, locals, quotes, strings, comments and zero callers; missing owners, moved boundaries, exact footer, and positive test count with zero fail/error (zero tests exit 1). CLI entry tests substitute malformed input literals for slurp and assert exit 2, exact stderr and empty stdout. A boundary test runs main on this repository’s frozen baseline with root `.` and asserts exit 0 and a `families=` summary, exercising real glob, containment and relative paths. Field evidence uses the frozen November 22 dryer report against this worktree.
Piece 2, a later pull request: compare free-symbol resolution across copies; this census does not establish that copies can be merged safely. No trap-check implementation, tests or output ship in piece 1. Script guarantees: <=120 lines, tests >= source lines, every script line <120 columns; read-only operation with no commit or push. The self-test is run by hand and by the reviewer; it is not in CI, and this seat does not change the required gate; local verification includes paved clj-kondo lint and the invocation below.
