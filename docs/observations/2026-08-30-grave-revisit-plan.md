# The grave-revisit plan — confirming the dead ends are dead

Date: 2026-08-30. Seat: fable@skiff. Gene's ask, verbatim: "don't we need to revisit all the
supposed dead ends and make sure there's really no promise there, experiments we can do to
confirm dead ends... come up with plan to systematically revisit each one."

**The organizing fact: the withdrawals were single-SOURCE; the kills are mostly single-CORPUS.**
Nearly every dead end was priced on retained sessions of the research program studying its own
tool. One shared confound → one experiment stress-tests most of the graveyard.

**Phase 0 result (harvest unread experiments) — already paid.** The route-hint experiment,
finished and never read: **Claude routes Surgeon-first 16/16 UNHINTED** (32/32 semantically
correct, branch experiment/claude-route-result-price-tag-20260829, commit bada0b40). The 0.5%
adoption rate is a CODEX property, not a tool property. Every reach-capped kill inherits a
Codex-only denominator.

## Triage by kill-grade

**Grade C — constructive kills (fixture-demonstrated wrong-subject). DEAD, no experiment earns
its cost.** Positional line numbers; opaque mnemonic labels; counts-as-identity. Reopening
condition already registered: independent effect identity binding label→owner+operation.

**Grade M — measured with controls, effect absent. DEAD on current stack; record TRIPWIRES, not
tasks.** Catalog shrink (98-call cohort, ~40.75ms fixed, no byte slope); EDN carriage (token
growth both tokenizers + generation-time parity 0.988); format-closure (fanout −20%);
copy-vs-compose (0.96x). Tripwires: retest EDN if the transport ever drops the JSON envelope or
the executor tokenizer family changes; retest catalog if the MCP client changes.

**Grade A — arithmetic on the circular corpus. THE SHARED CONFOUND; one experiment covers all.**
Declared-intent (93.7% net negative), guarded labels (99.3% consumed), mnemonic sizing (24.277%),
splice reach (insertions 28%), the write-side 94-second ceiling, the 6.0% addressable share.
→ **EXPERIMENT (dispatched, zero-model): the external-corpus census** — subject-repetition,
edit-shape, and reach counts on retained sessions of 2–3 NON-surgeon Clojure repos. If
production corpora repeat subjects or skew insertion-heavy, three kills reprice; if not, the
graveyard is confirmed with a de-confounded denominator.

**Grade S — screened with pre-registered thresholds that fired. Reopening conditions exist.**
- Parse gate (0/8 catchable): reopen at ≥15 genuine post-write reader loops/week on a FRESH
  population + shadow parser beating false refusals. Cheap to re-run on production windows.
- First-call enrichment (10.99% < 15% kill) — **but carries the standout anomaly: complete
  refusal lists halved re-reads, 48.0% vs 80.7%, observational, never causally tested.**
  → EXPERIMENT: ~20-episode A/B, complete vs truncated lists, dev-a. The 32.7pp delta is the
  largest untested effect on the board.
- Continuation refusals: window-unstable, 45% one-free-field copy prior; the designed 20-episode
  A/B was never run. Park behind the completeness A/B.

**Grade U — unresolved, never dead.** EDN robustness (0/30 both arms bounds nothing; ~150/arm
settles); **the model interview — never run, while all four inferred routing causes were
refuted.** Now sharpened by Phase 0 into a DIFFERENTIAL question: why does Codex route away from
a tool Claude chooses 16/16? → EXPERIMENT: matched interview/ablation, Codex vs Claude, same
task, on subscription lanes.

## Order and gates

1. External-corpus census (zero-model, dispatched) — reprices or confirms Grade A wholesale.
2. Completeness A/B (small dev-a spend) — the 32.7pp anomaly.
3. Differential routing interview (subscription, cheap) — the Codex-vs-Claude why.
4. EDN robustness n-completion — only if carriage ever matters again (tripwired otherwise).
Every experiment carries REACH, a registered prediction, and a kill criterion before it runs;
results enter the record only after second derivation. Grade C and M graves stay closed.
