# Proposal v2: programs-to-contracts cohort — measure the improvement (2026-09-10, after Astra review, eight edits applied)

Gene: "Propose something and have Astra review. Then go. Measure improvement."

## Claim under test
This pilot tests whether a Clojure exception and a task-routing plate improve independently accepted completion, and how each changes method choice. Census counts motivate hypotheses; they establish neither causes nor expected effects. The primary contrast is AC minus B in accepted completions by a common deadline, equally weighted across callers and T/R/I; report caller and intent strata. Gate-green oracle failures are the key safety outcome. Program share is secondary.

## Design
- Tasks. Freeze the full census hit list and its digest before drawing. An independent curator, without tool-support or outcome labels, reconstructs task intent and pre-edit bytes, deduplicates edit/repair episodes and records eligibility. Require an existing-file T body edit, R alias/use change, or I insertion after a named defn, a recoverable snapshot and an executable independent acceptance contract. Exclude generation-only, ambiguous or unrecoverable episodes with recorded reasons; do not exclude unsupported tool shapes. After freezing eligibility, publish a fresh seed; rank rows by SHA-256(seed || stable row ID), select four per family with at most one task per original session, and retain the ranked reserves. An independent reviewer approves every exclusion/substitution without seeing arm results. Preserve repository provenance; label necessary adaptations synthetic. If the full hit list is unavailable, apply this rule to the 60-row table and label the entire result a failure-enriched challenge pilot. Freeze tasks/oracles before runs. The broad census families cover 72.2% of program calls; this narrower balanced sample makes no census-prevalence claim.
- Arms. Freeze five prompt bundles: B = attested morning harness; A = B plus the exact installed Clojure exception; C = B plus experimental task-routing plate without exception; AC = B plus both; N = competent native Edit/Write/apply_patch policy, with batched patches allowed and no Surgeon. Publish full resolved instructions and diffs, removing accidental global/project contamination. Keep tool versions, schemas and docs identical in B/A/C/AC. These are policy treatments, not an unprompted adoption experiment. Estimate A−B, C−B, AC−A and AC−C; treat interaction as exploratory. Compare AC with N before attributing benefit to Surgeon.
- Capability manifest. Freeze a tested task-to-capability manifest before any scored run. E4 proves within+from/to for its rename; require_change refused, and alias_migration is not an assumed substitute for rename_alias. Exercise the exact advertised contracts, including deftest ownership. If insertion is unavailable, postpone the full pilot or publish a newly frozen reduced protocol before running any arms. Never change tools mid-cohort. The plate is an experiment-scoped override, not production admission of suspended or unwitnessed routes. Use the same entrance in all arms; a request-file convenience must not covertly turn MCP evaluation into CLI startup.
- Callers and runs. Two callers (claude-sonnet-5, claude-opus-5), 12 matched tasks, five arms: 120 scored runs. Pin model/settings and runner identities; use isolated fresh sessions/worktrees and randomized balanced task/caller blocks, at most four concurrent with bounded JVMs. Before comparison, collect six identical native-control calibration runs per caller (12 extra runs, excluded from the 120 task outcomes). Retain complete attestations and artifacts.
- Meter and improvement. Predeclare a 15-minute deadline per run, including required checks. Score the frozen first submission with held-out oracles; no private oracle feedback before scoring. Acceptance requires intent, preservation and all required gates. Report accepted, oracle-wrong/gates-green, oracle-wrong/gates-red, gate-only failure, noncompletion and unknown outcomes, all over assigned tasks. Unknowns never pass; publish sensitivity bounds. Show AC−B acceptance improvement first, with counts and paired uncertainty, then the joint silent-defect rate and complete wall. Keep paired task outcomes and discordant counts; use Wilson intervals only for marginal proportions. Report method sequence, task-level program use and separate census-compatible call share; refusals including unknown classification, recovery, first-attempt success, fallback, diff review and unintended changes. Complete wall includes all required gates, formatting, review, retries and queueing. Show failed run time and timeouts separately. Record model returns and tokens independently. Twelve per cell is a pilot; no general safety, equivalence or routing-admission claim follows from zero observed defects. Size a later study for a predeclared meaningful effect using the pilot's paired variation; no optional stopping at a win.


## Threats to validity
Apply the context, documentation, settings, freshness, oracle, interference and blinded-evaluation controls in Astra's review section 5 (2026-09-10-cohort-astra-review.md). Before use, every oracle must accept a correct witness and reject both an unmet-intent output and parseable collateral damage; include location-sensitive preservation and changed-owner checks with a non-rewrite-clj witness. Blindly audit method classification. Report disagreements and oracle coverage limits. Restrict conclusions to the frozen sampling frame and fresh-session setting; long-context field transfer is untested.

## Cost
Budget 132 runs including calibration: at the unverified three-minute assumption, 396 run-minutes, about 99 minutes at perfect four-way utilization, plus setup, queueing and review. The 15-minute cap permits up to 33 run-hours before parallelism. Re-estimate apparatus time after historical reconstruction and oracle validation; two hours is not established. Run this pilot to learn effect size and failure mechanisms. A broad rollout requires independent correctness, acceptable complete cost versus native, and an explicit decision on any safety/latency tradeoff.
