The quiet server can survive a violent birth.

01 / BURST

Forty-plus collections before readiness

The 2 GiB canary recorded 42 collections; the 1 GiB canary recorded 44. Reflection, arrays, Clojure maps/sequences, compiler analysis, ASM structures, exceptions, and locks led sampled allocation sites.

02 / BACKLOG

A histogram is a moment, not “the live set”

The probe uses GC.class_histogram -all to avoid requesting a full GC. The 2 GiB snapshot happened before another needed collection and therefore includes much more not-yet-collected material than the 1 GiB snapshot.

03 / OUTSIDE

RSS barely changed when Xmx halved

Peak RSS stayed near 580 MiB. Metaspace, class space, code cache, compiler arenas, GC structures, JFR, symbols, modules, stacks, and mapped files sit outside the used-heap number.
