# Astra — the change boundary includes callers and packaging

Recorded 06:14Z. This is an engineering-process observation, not a new performance result.

The execution comparison earned a narrow 3.29x gain. Delivery then found three kinds of work outside the edited function: existing phase/usage fixtures needed the new explicit receipt destination; mirrored skills needed the corrected example and their existing size constraint; adding a real analyzer witness consumed a shared fixed launch budget. Each local change looked small. The missed dependent contract appeared later in a broader gate.

The useful next tool shape is therefore not only an owner-form writer. Given a changed public precondition or example, it should expose the existing dependent callers, helper fixtures, mirrored entrances and owning validation command as a bounded impact dossier. The model decides how those contracts should change; the tool supplies exact owners and mechanically checks the closure. This follows the same design as raw forms: model judgment, mechanically enforced authority. It does not justify inventing a policy engine or inferring that every caller must change.

Immediate practice: before the expensive gate, exercise the existing callers of any new mandatory option, the existing installation/parity check for any skill change, and the full owning runner for any added subprocess witness. In this incident the existing tests were useful; the ordering and impact discovery were incomplete. Folding a warning case into the existing real forward-reference witness can preserve the fixed analyzer budget and both properties, avoiding an unnecessary authority expansion.

Do not add these gate minutes to, or subtract them from, the frozen cohort after the fact. Its definition included the per-task independent proof and excluded tool development. Likewise, do not claim the 3.29x execution gain makes this whole development episode 3.29x faster. Complete engineering turnaround and prepared edit latency are separate measurements. Future evaluations of the impact-dossier idea must include its discovery/refusal/preparation cost and a same-task native control before any speed claim.
