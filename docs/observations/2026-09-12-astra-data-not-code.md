# Astra: what should be data but isn't (read-only consult on bb-rewrite-tower 3b6d5357, 2026-09-12)

Gene, verbatim: "Do we have bad interface or something that should be data but isn't? Ask Astra too. Something to make it safer and something that would make rich hickey smile"

**The main problem is facts coupled to incidental representation:** refusal meaning to exception wrappers, evidence to generated source, authority to ambient paths, and identity to line numbers. Astra independently reviewed the tree and agreed with the bounded safety recommendation below.
Read-only assessment of clean HEAD `3b6d5357`; no edits, JVMs, suites, or servers.
**(a) Five candidates**
1. **Refusal classification should be a value independent of runtime exception presentation.** [edit_dsl.clj:426](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/edit_dsl.clj:426) walks exception causes for `:error-type`, then recognizes three English message fragments to classify forbidden symbols. The concrete failure was JVM SCI wrapping the typed host refusal and spelling an unresolved symbol differently: three JVM assertions failed while bb passed. That is documented, and repaired, in [attempt22/xray-findings.md:8](/home/forge/src/clj-surgeon-bbtower/docs/observations/2026-09-12-bbtower-block-b/attempt22/xray-findings.md:8). Keep domain refusal maps and runtime-error normalization separate; unknown runtime errors should remain unknown rather than acquire meaning through prose matching. **The historical wrapper defect is fixed; message dependence remains.**
2. **Runtime evidence should be consumed as an evidence artifact, without generating executable source around it.** [attempt20/fold.clj:52](/home/forge/src/clj-surgeon-bbtower/docs/observations/2026-09-12-bbtower-block-b/attempt20/fold.clj:52) writes EDN, then constructs a textual patch containing a quoted map and code that reconstructs receipt paths. [lane_manifest.clj:884](/home/forge/src/clj-surgeon-bbtower/test/clj_surgeon/lane_manifest.clj:884) additionally selects attempt22 versus attempt23 provenance through namespace-specific branching. Prefer explicit evidence rows—subject, runtime, receipt references, measurement epoch, capability classification—and a pure assignment function. The temporal failure already occurred: historical calibration consulted *today’s* assignments until repaired to read membership from its own receipt ([attempt20/REPORT.md:33](/home/forge/src/clj-surgeon-bbtower/docs/observations/2026-09-12-bbtower-block-b/attempt20/REPORT.md:33)). That was a time/provenance defect, not an EDN-versus-Clojure defect.
3. **Effective write authority should be an explicit invocation value.** Artifact selection honors XDG at [receipt_artifacts.clj:31](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/receipt_artifacts.clj:31); workspace state interprets `state-home` as a *home prefix* at [mcp_workspace.clj:75](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/mcp_workspace.clj:75); analyzer locks use separate overrides at [mcp_process.clj:78](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/mcp_process.clj:78); events resolve another location at [telemetry_events.clj:94](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/telemetry_events.clj:94). A map should distinguish purposes, permitted effects, resolved destinations, and override provenance. The concrete failures included denied helper/oracle writes and Git writing shared worktree metadata outside correctly selected scratch ([attempt18/envelope-census.md:18](/home/forge/src/clj-surgeon-bbtower/docs/observations/2026-09-12-bbtower-block-b/attempt18/envelope-census.md:18)). Merely relocating temporary files did not authorize those other effects.
4. **Sleep exemptions should identify an operation, not its physical line.** [lane_manifest_test.clj:1160](/home/forge/src/clj-surgeon-bbtower/test/clj_surgeon/lane_manifest_test.clj:1160) declares `file → line → prose reason`; its scanner recognizes calls with a regex at [line 1183](/home/forge/src/clj-surgeon-bbtower/test/clj_surgeon/lane_manifest_test.clj:1183). Use an owner, exact call/occurrence, purpose, and relevant deadline as data; derive the current line for diagnostics. Today an unrelated insertion moved a sleep from 253 to 288, causing two failures and a pin-only repair ([attempt21/REPORT.md:42](/home/forge/src/clj-surgeon-bbtower/docs/observations/2026-09-12-bbtower-block-b/attempt21/REPORT.md:42)). The scanner also documents mistaking its own regex and a docstring for calls.
5. **The refusal vocabulary should be declared independently of expression syntax.** [mcp_hot_verify.clj:143](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/mcp_hot_verify.clj:143) explains why a comparison was hoisted: refusal enumeration had mistaken its operand `:closed` for a refusal kind. An inventory mechanism was dictating harmless implementation structure. Extend the existing [probe refusal registry](/home/forge/src/clj-surgeon-bbtower/docs/intent/probe/refusals.edn:15) into a constructor/contract boundary, with independent reachable-refusal witnesses. Moving keywords into EDN alone would not prove completeness.
**(b) Three poor interfaces**
- **Refusal propagation has inconsistent shapes even within probe.** [request-problem](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/probe.clj:31) returns a refusal or nil; [probe-reload-order](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/mcp_hot_verify.clj:230) throws; [probe!](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/mcp_hot_verify.clj:271) reconstructs a returned refusal and forwards selected fields. Callers must know both transport and domain conventions. One domain-result shape would reduce translation and field-loss opportunities.
- **Location configuration uses similar names for different concepts.** `state-home` means “prepend a substitute home,” whereas `CLJ_SURGEON_ARTIFACT_ROOT` means “use this final artifact root” ([workspace](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/mcp_workspace.clj:75), [artifacts](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/receipt_artifacts.clj:20)). This makes isolation depend on remembering each writer’s resolution algorithm.
- **The measurement producer hands its consumer a source patch.** [fold.clj:54](/home/forge/src/clj-surgeon-bbtower/docs/observations/2026-09-12-bbtower-block-b/attempt20/fold.clj:54) must locate a particular `def`, serialize replacement code, and manufacture patch syntax. A consumer reading validated evidence rows would remove that structural dependency while retaining the existing statistical witnesses.
**(c) ONE change with the best safety return**
**Add trusted invocation-envelope admission to the existing common artifact boundary.** Start at [writable-root!, directory, and target](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/receipt_artifacts.clj:137), rather than first migrating every writer. The audit identifies many publication families already sharing this entrance ([attempt12/write-audit.md:31](/home/forge/src/clj-surgeon-bbtower/docs/observations/2026-09-12-bbtower-block-b/attempt12/write-audit.md:31)).
The envelope comes from trusted launcher context, following the existing [operation authority rule](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/operation_algebra.clj:56); request fields cannot widen it. Before directory creation or publication, return:
```clojure
{:error-type :write-outside-envelope
 :effect :receipt-publish
 :path requested-path
 :resolved-path resolved-path
 :envelope-id envelope-id}
```
**Witness:** drive actual publication with an otherwise valid, owned, disk-backed destination outside the envelope. Independently observe zero directory creation/publication and unchanged outside bytes. Include absent-parent and symlink-escape cases, plus successful authorized publication. Exercise the ledger path as well as workspace-specific receipts.
Keep Landlock enforcement where used. This addition supplies earlier, intelligible refusal; it does not mediate arbitrary subprocess writes or eliminate filesystem races. Its coverage claim is the shared artifact boundary, not every writer.
**(d) ONE change that would make Rich Hickey smile**
My interpretation, not a quotation: **replace sleep-line pins with values identifying the test operation.**
The identity is the particular sleep in its owning test; the line is its current place. Its temporal purpose—polling versus deliberately spaced stimulus—is another fact. Store those facts separately and derive locations from the current source. Preserve review when the call, owner, cardinality, or temporal contract changes.
This removes the coupling between unrelated text insertion and policy approval, demonstrated by [attempt21’s pin-only repair](/home/forge/src/clj-surgeon-bbtower/docs/observations/2026-09-12-bbtower-block-b/attempt21/REPORT.md:42). It favors simplicity over the local ease of “just change one number.” Crucially, this defect already lives in a map: choosing the right identities matters more than choosing EDN.
**(e) Where I disagree with Fable**
**Refusals:** “Exceptions instead of values” is too broad. [probe.clj:24](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/probe.clj:24) already returns refusal values, and [line 42](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/probe.clj:42) derives verdicts purely. Typed exceptions also carry data and can legitimately unwind evaluation. The witnessed defect was losing that data across a wrapper boundary; converting every internal throw into an ordinary return would require ensuring no builder continues with a refusal as its input.
**Manifest:** The quoted map is data, and provenance is not absent. [lane_manifest_test.clj:225](/home/forge/src/clj-surgeon-bbtower/test/clj_surgeon/lane_manifest_test.clj:225) reads receipts, checks distinct runs and identities, and recomputes statistics. Fable’s artifact proposal improves the producer/consumer boundary, but should not be sold as introducing evidence where none exists. Preserve the separation between measured performance, correctness controls, and explicitly registered capability limitations.
**Places and safety:** The current tree does not have 21 wholly independent, unguarded writers. Common artifact validation already checks root suitability and descendant containment ([receipt_artifacts.clj:63](/home/forge/src/clj-surgeon-bbtower/src/clj_surgeon/receipt_artifacts.clj:63)); attempt18 records repaired reachable escapes and a passing restricted gate ([envelope-census.md:113](/home/forge/src/clj-surgeon-bbtower/docs/observations/2026-09-12-bbtower-block-b/attempt18/envelope-census.md:113)). Fable’s missing invocation-authority point survives; “Landlock is the only predicate” does not.
**Everything derived, never authored:** Measurements and verdicts should be derived; authority and intended policy must still be declared. Observing a write does not authorize it. The existing [receipt-boolean registry](/home/forge/src/clj-surgeon-bbtower/docs/intent/receipt-booleans/registry.edn:13) already makes a sound distinction: probe omits a meaningless constant verification boolean and retains pending cold proof. More data is useful when it separates facts, policy, and evidence—not when it makes them interchangeable.
