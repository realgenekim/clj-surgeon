## Agreed (both answers, independently)
- One tower: bytes and objects → clj-splice → domain verbs → guarded publication → execution/review → work protocol → append-only ledger → pure folds → status/resume/board/log/report. Every boundary emits subject-bound evidence; the same three things cross every boundary: a request as data, a typed refusal that names its repair and its native failure or none, a receipt with mutation state first.
- One append-only event ledger that every one-shot writes; the resume note, the board and the captain's-log facts are folds over it, never hand-maintained state. Interpretations and decisions stay authored, attached to event ids.
- Briefs as data with enforced slots; reports as data with required fields; one launch verb with a typed handle and a reconnectable await; context by reference; rules as refusals in the verbs.
- Accretion: findings become witnesses in the owning layer; refusals carry native_failure with a completeness check; bets are folded against a frozen registry; the census re-runs as a measure verb; memory shrinks to what is about Gene.

## Where Astra corrected Fable (adopted)
1. **The ledger observes; it does not authorize.** An entry is not true because it was appended; authority stays with the verb that executed and the check that ran. Coverage by producer is a field; a stale note is an imported observation with its timestamp, never a present-tense fleet view.
2. **The work protocol is a layer of its own.** Obligations (ready / owed / blocked / discharged) with owner, reason, unblock condition and trigger; "parked" is a decision with a reopening condition; "landed" requires remote confirmation; installed and accepted are separate facts. A completed assignment discharges its obligations and exposes the next authorized ready task; a blocked one names its owner without idling unrelated work.
3. **Stop conditions measure authority, not prose length.** The "contract change larger than a paragraph" stop idled a round; the rule is: stop only when the change exceeds the builder's granted authority, and say what authority would resolve it.
4. **An executable resource contract, not a prose fence.** "One JVM, no servers" made Astra unable to run the gates it was asked for; the system hands an ineligible check to an eligible executor and preserves it as owed. Environment (BABASHKA_PRELOADS, CODEX_HOME, AGENTS.md) is an input, resolved and hashed before launch.
5. **Vertical slices, not horizontal layers, as the build order.** Each block ends with a demonstrable "done": a fresh agent reconstructs the slice from the ledger alone.
6. **At-least-once plus idempotent folds**; a crash between action and terminal append yields UNKNOWN and a reconciliation event, never a repeated mutation.

## The plan: three vertical blocks, then product measures on top
**Block 1 — one run lifecycle and a truthful status slice.** run-bg and the ship path write the event envelope (schema, event_id, task_id, run_id, attempt, cause, subject{repo,base,tip,tree}, kind, utc, elapsed, payload, artifact digests) through a locked append writer with sequence and checksum; unique immutable run directories; a typed handle; a reconnectable await. `board` folds running / terminal / unknown / owed with coverage by producer and as_of. Witnesses: fast exit, spawn failure, duplicate attach, crash-before-terminal, restart reconciliation. DONE when a fresh agent reconstructs that slice with no logs and no resume note. Retires: pid wait loops, hand-copied state for that slice.
**Block 2 — one executable build-to-review packet.** brief.edn (owner, base, rules-profile, inputs by id, order, stop-by-authority, deliverable, budget) and report.edn (verdict, findings, measurements, commits, least-sure, disagreements); skills/environment/catalog/gate obligations and resource needs resolved BEFORE launch; detached subject and immutable patch manifest; the five refusals above; an ineligible gate handed to an eligible executor and kept owed. Witnesses: the stale skill, the occupied branch, the one-JVM conflict, the stale catalog pin, the self-referential manifest. DONE when each fails cheaply or schedules correctly before review, and a delta round carries no stale claims. Retires: renamed branches per round, copied fix boilerplate, paragraph-count stops, four of the nine stop classes.
**Block 3 — one finding-to-witness-to-report loop.** The receipt-boolean findings and the refusal registry connected to replayable witnesses; one completed experiment folded against its frozen bet registry into the morning-report facts; the cohort apparatus becomes the `measure` verb. Witnesses: duplicate ingestion, scorer revision, missing evidence, a reopened finding. DONE when another agent answers what changed, what failed, what remains owed and which bet lost from one query. Retires: hand-scored bets, hand-written report tables.
**Then, as measure runs on the new spine:** the long-context replication (Claude), Codex arm N and the M/N cost ratio plus reproducing the .codex/config.toml delivery failure, the monthly census. The rewrite-clj upstream issue and the library's own repository on Gene's word. A third verb only after Block 2.
