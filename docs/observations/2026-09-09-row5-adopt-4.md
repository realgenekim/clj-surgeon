## WHY THE GATE STILL FAILED: the residual is no longer coverage, it is INDEPENDENT WITNESS

Arm E3's residual was a *coverage gap* — 6/6 arms named the `ns` form and the footprint as
things `:facts` did not cover. Those are covered now, and the arms say so. What the 15 surviving
answerable reads are is a different thing, and the callers state it in their own words:

* Z1 — `git status` is "an authority **independent of the receipt's own snapshot** for which
  files differ."
* Z3 — "a five-second falsifier **from a different tool**, and a receipt that agrees with an
  independent probe is worth more than a receipt alone."
* Z4 — `git status` is worth 200 ms because `:footprint`'s scope "explicitly excludes uncaptured
  paths, i.e. **it is blind to a stray non-Clojure file**; `git status` is not."
* Z6 — "it is the one claim where a self-report and a repair are **indistinguishable if the tool
  were wrong**."
* Z5 and Z6 both re-read the `(comment …)` block after `:comment_edits` had already stated the
  edit, for the same declared reason: it is the one edit the tool authored *inside prose*.

**Adding facts cannot remove this class of read**, because the caller is not missing information
— it is deliberately declining to take the tool's own record as its only witness on the claims
that would be indistinguishable from a repair if the tool were wrong. That is correct caller
behaviour under this house's own doctrine, and on the preregistered meter it scores ANSWERABLE.

Corroborations rising while answerable falls is the same signal from the other side:
**7 → 11 (+57 %)** as answerable fell 24 → 15 (−37.5 %), so total inspections barely moved
(32 → 27, paired 0.92). Arm E2's learning — *"a verifiable negative invites verification"* — has
now fired for a third consecutive cohort, and this time it is the whole story.
