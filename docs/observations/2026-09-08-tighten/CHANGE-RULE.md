# CHANGE RULE — authority is the fixed point

Standalone block; inline this file verbatim where the instrument's production entrance needs it.
Drafted 2026-09-08 from Astra's daily design and the merged 12:55Z records decision.
This rule governs changes to the machinery that captures, repairs, grades or distributes improvements, including this rule itself.
It does not freeze implementation forever. It fixes who can change the meaning of success and what evidence must survive.

## Roles and boundary

- **Gene** owns intent and rulings that change meaning: acceptance, routing admission, exclusions, clock boundaries, task-set policy, or the boot block's obligations. Silence, elapsed review budgets and a tidy board are not rulings.
- **Builder** proposes and repairs an isolated candidate, retaining the motivating evidence. The builder cannot replace the active reference, choose its own favorable task set or issue its own authoritative grade.
- **Instrument steward** is a named independent person/seat appointed for the package, with access to frozen cases and raw events. It verifies the production entrance and signs qualification separately from construction. Merely changing model names is not independence.
- **Independent recorder/acceptor** owns prospective assignments, clocks, observation and acceptance evidence outside the candidate. A worker's self-report is an input to check, not its own certification.
- **Reviewer and landing owner** apply existing review and branch authority. The mayor schedules and lands; that role cannot silently move the bar. Instrument qualification does not waive required intent reviews or final-candidate proof.
- **External duty supervisor/rung 2** can stop affected authority and summon repair. It cannot weaken a gate or publish a fix by virtue of incident command alone.

Record actual owner identities before use. A missing steward or independent recorder leaves qualification pending; it does not delegate their authority to the builder.
No receipt may be produced by the party it grades: an independently controlled runner may emit facts about a builder; the builder may not control its selection, evaluator or retained evidence.
Disclose shared-account/write-access limits. A different PID or hash alone does not establish an adversarial trust boundary.

## Freeze the current epoch before optimization

Bind a retained package manifest to:

- prospectively assigned task IDs, task-set membership policy and intended outcomes;
- acceptance meaning, required checks and their production argv/configuration;
- baseline, oracle, classifier, observer and harness bytes/versions;
- effective prompt, managed boot blocks, overlays and delivery surfaces;
- native control, resource/venue policy, clock endpoints and registered noise;
- subject workspace/candidate identity, evidence retention and owner bindings.

The protected outcome is request-to-independently-accepted completion, with every assignment and attempt retained.
Do not shift setup off-clock, drop failed attempts, reinterpret pending as pass, or weaken proof while keeping the old epoch label.

## Change procedure

1. **Capture the triggering failure.** Retain literal input, expected outcome, actual events, verdict, package hash, candidate and finding ID. If an oracle missed a defect, its miss is a separate linked finding repaired with the product fix, not postponed.
2. **Build an isolated candidate.** Retain the current trusted package unchanged. Propose the narrow implementation diff, affected obligations and anticipated verdict changes. Do not swap the grader underneath a live run.
3. **Classify the change before promotion.** An implementation repair preserving approved meaning follows existing review authority. Any meaning change listed above requires Gene's explicit ruling, linked to the candidate and old/new intent. Ambiguous classification stays pending with the steward; it is never silently deemed mechanical.
4. **Steward verifies at the production entrance.** Run old and candidate instruments against the same frozen positive AND negative cases. Use the real launch, ownership, evidence and terminal-result path, not a special test-only bypass. Retain commands, input hashes, raw events, exit statuses and outputs.
5. **Use literal independent anchors.** Include a valid success and the relevant wrong-root, failed-worker (the retained exit-17 case), stale-final-candidate, intended-assertion-red, pending-proof and missing-observer cases. Add the triggering counterexample; unrelated all-green tests cannot substitute. Cases must distinguish a correct refusal from a false conviction.
6. **Publish the verdict matrix below.** Every changed verdict needs a reason anchored to the approved intent or Gene's new ruling. Preserve unchanged cases too: otherwise a repaired negative can hide broken positives. Run bounded independent adversarial sampling; retain its method and limits.
7. **Qualify, then promote through existing authority.** Name exactly which claims are qualified, pending or suspended. A correct candidate may still lack delivery or timing proof. Issue a new instrument epoch for a changed accepted instrument; retain the old manifest and raw evidence.
8. **Deliver the new epoch.** Announce every affected Claude/Codex seat before changing prompt blocks; install from the canonical source, check actual resolutions/hashes and current-session uptake. Run fresh changed-seat canaries; append consumer-visible records. Old active sessions do not acquire new instructions because a file changed.
9. **Regrade append-only.** Link each regrade to the original run, original and new instrument epochs, evidence hashes, matrix and ruling. Keep original verdicts intact. Missing observations remain unknown; a new parser cannot reconstruct uncaptured execution.
10. **Re-establish comparisons.** A changed instrument/control environment requires fresh matched controls and its registered variance-floor procedure where applicable. Historical cross-epoch timing is not a new speed claim. Retain failures and unfinished tasks in the prospective denominator.

## Old/new verdict matrix (required artifact)

One row per frozen case; bind a separate matrix artifact to the candidate qualification receipt.
The column schema is:

| Field | Required meaning |
|---|---|
| `case_id`, `case_kind` | Stable corpus ID; positive, negative or independently selected challenge. |
| `input_hash`, `literal_expected` | Exact immutable case and independently inspectable expected result. |
| `reference_epoch`, `reference_hash` | Old instrument package used in this run. |
| `candidate_epoch`, `candidate_hash` | Proposed new instrument package used in this run. |
| `production_argv`, `environment_ref` | Actual entrance and attested execution environment, not a display alias. |
| `old_verdict`, `new_verdict` | Actual results, including errors/unknowns; no blank cell means passed. |
| `old_evidence`, `new_evidence` | Retained raw events, terminal exits and structured checks, each hashed. |
| `changed_reason`, `intent_or_ruling_id` | Explanation for every difference and the authority that licenses it. |
| `steward_id`, `qualification` | Independent verifier; passed, refused or pending with exact scope. |

A matrix populated only with the builder's predictions is a proposal, not qualification.
Newly added cases must be executed on the old instrument too; inability to replay is recorded as unknown with its cause.

## Stop and resume

A credible defect that could falsely authorize release invokes scoped Andon immediately, even if no bad release has occurred.
A shared/shipped wrong-subject mutation or corruption/security/unknown-state risk also qualifies.
Stop affected release/mutation authority; preserve evidence, isolated diagnosis, tests and reversible repair.
An isolated experiment failing safely remains stopped with its named owner; it is not automatically a fleet incident.

The pull records what stopped, affected surface and evidence; honest incomplete blast radius is allowed.
Use the registered direct delivery path and retain delivery/acknowledgment receipts; storage alone is not delivery.
House rules give the mayor acknowledgment within 5 minutes, then rung-2 incident commander → Gene → named second human.
An undelivered alarm escalates immediately; no `--if-silent` default may turn absence of delivery into consent.
No rung-2 officer means the implicated scope remains closed. Irreversible scope reaches Gene.
Resume requires an explicit authorized owner, repair and independent qualification evidence, with the stop ID discharged by a new receipt.

## Prevent an infinite tower of graders

The steward's judgment is fallible. Anchor it in literal outcomes, retained raw events, frozen positives/negatives and bounded adversarial sampling.
Gene periodically samples accepted work and a failure/pending item against their original requests.
Do not build another unbounded grading hierarchy or erase an uncomfortable disagreement by averaging it away.
A change to this rule follows this same procedure; it cannot grant its author authority to approve itself.
