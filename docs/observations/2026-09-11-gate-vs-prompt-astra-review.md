## 1. H confounds obstruction with helpful repair

H versus AC estimates the delivered package: recognition, blocking, extra context, and repair information.
It does not isolate “a refusal WITH ITS REPAIR moves the hand.” A blocked program can become an Edit, another program, abandonment, or Surgeon.
Add **H0 = AC + exactly H's recognizer, scope, exit status, timing policy and logging; the only caller-visible message is `not run`.**
Keep Edit/Write and alternate shell routes available identically. H−H0 is the incremental effect of the repair bundle; H0−AC is obstruction.
Do not equate either contrast with a pure wording effect: H supplies additional task-specific information as well as different language.
Generate repairs only from the attempted command, available source and common task instructions; never from the private oracle or expected output.
A shell command need not identify a unique form. Return “target unresolved” when it does not; do not manufacture a confident filled request.
Freeze repair-template selection and its capability witnesses before runs. A demonstrated insert contract is not a demonstrated alias-rename contract.
I decline H2 now: adding another wording before establishing exposure and H−H0 spends runs on the wrong uncertainty.

H also blocks `.edn` heredocs: that can block creation of the repair's own request file. Exempt a narrowly designated request-only directory, identically in H/H0, and test that source writes through it are not silently misclassified.
Treat arbitrary shell-write detection as bounded recognition, not universal enforcement. Test variables, quoted paths, script files, absolute interpreters, redirects, `tee`, `bb`, and read-only `sed -n`.
Record covered attempts, blocked attempts, unsupported shapes, false positives and bypass writes. Zero observed program writes is an outcome, not a property guaranteed by a command-name list.

## 2. Sonnet is an exposure problem, and Opus AC is too

The null cohort's Sonnet AC has 12/12 editor finals and zero task-level program use; Opus AC also has zero task-level program use.
With the same AC prompt, H is likely dormant for both. An agent cannot respond to a refusal it never receives.
The registered ≥25% Sonnet means **at least 4/13**, not “anything above zero”; ≥50% Opus means **at least 7/13**.
Those are falsifiable forecasts, but the prior evidence does not support their mechanism. Keep them as historical bets, not plausible expectations rescued by a lower falsification bar.
If no H hook fires, conclude “the deployed hook did not reach this caller on these tasks”; the conditional repair thesis is untested.
Do not conclude “the model decides, neither prompts nor hooks work.” If H/H0 do fire and callers choose Edit, obstruction changed the hand without demonstrating Surgeon adoption.
Primary comparisons remain over ALL assigned tasks; exposure-conditioned recovery is descriptive because exposure is selected by the caller.
An auxiliary forced-refusal continuation could isolate recovery on identical attempted commands, but would be a separate, explicitly artificial experiment, not these natural task runs.

## 3. G must disclose damage and must actually gate the candidate

PostToolUse means the write already happened. Retain pre-image, attempted post-image, exact diff, call ID, detector results, refusal, restoration result and final hash in the ledger.
The message must say: `write occurred; candidate rejected; restoration verified` OR `restoration failed/unknown`; never imply “nothing was written.”
Keep two outcomes: attempted damage caught, and damage remaining at final acceptance. A restored wrong write remains an attempted defect.
Count its repair turns and elapsed time. Do not classify the automatic gate or restore as caller-chosen Surgeon editing.

The existing `admit_clojure_patch` contract takes a PATCH against a pre-image, not simply “the resulting bytes.” It reports changed owners; it does not intrinsically know which owner changes were unintended.
G needs a nonblocking pre-edit snapshot capture plus serialized post-edit admission against an isolated copy of that snapshot, using the exact delta and trusted verification configuration.
Never apply the same patch again against the already-edited worktree. Restore only when its current hash still matches the rejected candidate; preserve earlier successful edits, new-file absence, modes and concurrent changes.
Unknown admission is not green. A conflicted/failed restoration stops that run and remains visible, rather than overwriting intervening work.
If a task-specific allowed-owner set is supplied, disclose it as an additional intervention and give equivalent preservation information to all callers; do not import a hidden answer key into G.
E4's route-string corruption parses and can occur inside legitimately changed owners. Require a separate preflight replay of its known wrong candidate and the correct candidate; report precisely which detector rejects it, or admit the gate misses it.
“Catches E4 if someone makes the mistake” is otherwise vacuous when nobody does. Natural runs estimate damage incidence; injected candidates establish detector coverage separately.
G can alter later route choices after its first refusal, so “after the hand” does not imply unchanged final mechanism.

Six H/Sonnet repetitions on one task estimate neither native wall variance nor a ±1-task equivalence margin across 13 heterogeneous tasks. Calibrate native per caller and report paired task discordances; do not borrow seconds of wall spread as adoption uncertainty.
